The source set fails badly. Of six sources supplied, three are either fabricated or non-resolving (s2, s5, s6), which is an explicit deal breaker in the research intent. One source (s5) is an unverifiable reference to the 2019 Microsoft Japan press release — another named deal breaker, since it is non-European, vendor self-reported, covers only a single month, and predates the 2022 recency requirement. The one substantive source (s1, the Autonomy Institute UK pilot report) is real, recent, and correctly states the 1.4% trial-period revenue figure, but Autonomy co-designed and co-ran the trial it reports on, the sample is self-selected with no control group, and the data is UK-wide across diverse sectors rather than from a small European software firm. The Destatis landing page (s4) is a credible government source but contains no actual data — it is a navigation page, not a citable finding. The Reddit link (s3) returned effectively no content and is anonymous user-generated commentary with no evidentiary value. Critically, no source provides a European software or knowledge-work case study under 100 employees, none addresses German legal constraints (Arbeitszeitgesetz, Kurzarbeit, collective bargaining), and none distinguishes output-per-hour from total weekly output. This evidence base should not be relied upon for a consequential operational decision; roughly half the citations are fictitious and the remaining ones do not meet the stated success criteria.
