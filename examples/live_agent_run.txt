The source set fails catastrophically on nearly every success criterion. Of twelve sources assessed, only one (s1, the METR 2025 RCT) is a verified, independent, primary study with full provenance — and it found AI tools made experienced developers 19% slower on real tasks. The single verified vendor study (s3, GitHub's own blog) relies on self-reported satisfaction metrics rather than measured productivity, which the intent explicitly flags as a deal-breaker conflation. The DORA 2025 report landing page (s4) was fetched but contained no actual findings, just a download page with vendor-partner logos. Half the sources (s8–s12) have no URL at all and exist only as inline paraphrases with zero traceability. An engineering VP could not defend any recommendation based on this evidence set — there is essentially one real independent study that says AI tools slow experienced developers down, one vendor marketing piece, and a collection of unverifiable or fabricated references filling in the rest.
